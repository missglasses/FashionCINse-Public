# FashionCINse 👗

> *Fashion Sense + CIN(me) = Fashion CINse *

I've always loved fashion, and as someone currently pursuing a career in web development, I wanted to create a project that combines both of my interests. **FashionCINse** is my way of expressing my personal style while experimenting with UI design, front-end development, and a nostalgic desktop-inspired aesthetic.

## ✨ About

FashionCINse is a digital fashion portfolio inspired by the classic Windows 95/98 desktop experience.

Instead of displaying outfits in a traditional gallery, each look is presented as if it were a **`.BMP` image file** stored inside an old computer folder. Every outfit has its own "file," complete with pixel-inspired frames, filenames, and numbered entries—bringing together vintage software nostalgia and modern fashion.

The project serves as a digital closet where I can showcase my favorite outfits, fashion inspirations, and styling ideas through a playful retro interface.
